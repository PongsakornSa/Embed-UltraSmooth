## ปัญหาที่เจอ และวิธีแก้
- เปิด `localhost:8080` ไม่ได้ เพราะยังไม่ได้เปิด server ให้รัน
  `python -m http.server 8080` ในโฟลเดอร์ `dashboard` หรือเปิด `index.html` ตรง ๆ
- ย้าย gateway ไปเสียบอีกเครื่องแล้วไม่มีข้อมูลขึ้นราว 15 นาที ต่อมากลับมาออนไลน์เอง
- `rain_raw` = 262 ทำให้เว็บขึ้น "ฝนตก" น่าจะเป็นเพราะเซ็นเซอร์ฝนยังไม่ได้ต่อ ขาเลยลอย
- อัปโหลดไป COM3 ไม่ได้ในครั้งแรก ("port doesn't exist") ลองใหม่อีกครั้งก็ผ่าน
- อัปโหลดที่ 230400 ขึ้น "Could not open COM3" ทั้งที่พอร์ตว่าง ลดเหลือ 115200 แล้วผ่าน
  (ตั้งใน `node/platformio_local.ini`)
- เสียบ MQ-2 กับ node แล้ว COM3 เปิดไม่ได้ (`OSError 433`) ถอด MQ-2 ออกก็อัปโหลดได้
  น่าจะเป็นที่สายของ MQ-2 ช็อต หรือ heater ดึงไฟจาก USB จนไฟตก ต้องเช็คสายก่อนต่อกลับ
  ถ้าสายถูกแล้วยังเป็น ให้ใช้ไฟ 5V แยกเลี้ยง MQ-2
- ผลการอ่านของ node ตอนไม่ได้ต่ออะไรเลย: PMS5003 และ SHT31 `MISSING`, Rain raw=0, MQ-2 raw=0
- เคยคิดว่า MQ-2 ต่ออยู่ที่ node แต่จริง ๆ ต่ออยู่ที่ gateway จึงแก้ firmware gateway ให้อ่านแทน
